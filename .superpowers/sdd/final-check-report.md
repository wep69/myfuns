### WARNING fix: malformed Rd in `plot_reg_equation.Rd`
- **Root cause:** The `.Rd` file contained literal `\u00e9`-style Unicode escape sequences (e.g., `\u00e9`, `\u00e7\u00e3o`, `\u00edtulo`) that Rd doesn't understand, plus a stray `\figure{plot_reg_equation_example.png}{...}` macro outside any section.
- **Fix:** Replaced all `\u00XX` escapes with proper UTF-8 characters (é, ç, ã, etc.) and removed the invalid `\figure{}` macro. Also updated the roxygen source in `R/plots-estatisticos.R` to use UTF-8 instead of `\u00XX` escapes.
