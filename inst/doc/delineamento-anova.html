Delineamento, resumo descritivo e ANOVA

Dados didáticos

dados_dbc <- expand.grid(
  bloco = factor(1:5),
  tratamento = factor(c("Controle", "A", "B", "C"))
)
dados_dbc$produtividade <- 42 +
  c(0, 5, 9, 7)[dados_dbc$tratamento] +
  rep(c(-2, 1, 0, 2, -1), each = 4) +
  rnorm(nrow(dados_dbc), 0, 2)

auditar_delineamento()

A auditoria é realizada antes do ajuste. Ela descreve níveis, combinações previstas, células ausentes, respostas ausentes, balanceamento e, quando unidade é informada, duplicação do identificador da unidade experimental.

Exemplo 1: DBC completo

aud1 <- auditar_delineamento(
  dados_dbc,
  tratamento = tratamento,
  bloco = bloco,
  resposta = produtividade
)
aud1

#> -------------------------
#>                         item valor
#>                  Observações    20

#>             Células ausentes     0

#>           Respostas ausentes     0
#>                   Balanceado     1

#> Mensagens:

O CV é apresentado como descrição e não como critério universal de qualidade. Respostas de contagem, proporções ou médias próximas de zero requerem interpretação específica.

Quando effectsize está instalado, os tamanhos de efeito são obtidos diretamente por esse pacote. Na ausência dele, myfuns consegue calcular eta² parcial básico para modelos lm, mas sem intervalo de confiança.
